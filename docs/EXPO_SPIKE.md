# Expo-spike: оценка натива БЕЗ кода (см. V28, ADR-05)

> Статус: `исследование`. Решение о нативе — только по гейту 1000 платных (см. V32).

## Что покрывает PWA уже сейчас
- Install (Android prompt + iOS Add to Home), offline shell + spreads + карты (см. T19).
- Push через Web Push API (см. U21) — на iOS 16.4+ только из Add-to-Home.
- Камера/3D — WebGL в PWA равен нативному WebView.

## Gap-лист PWA vs native (см. V29)
| Возможность | PWA | Натив |
|---|---|---|
| Пуши iOS <16.4 | нет | да |
| Богатые пуши (картинки, кнопки) | частично (Android) | да |
| Store-трафик/фичеринг | нет | да |
| Face ID для входа | нет (WebAuthn частично) | да |
| Фоновая гео/HealthKit | нет | да |
| Виджеты iOS/Android | нет | да |

## Оценка (для ADR гейта)
- Expo RN + Tamagui/NativeWind: переиспользование ~40% (дизайн-токены, API-клиент логика).
- R3F-храм переносится почти 1-в-1 (react-three-fiber + expo-gl).
- Цена: 2 стора, ревью, пуш-сертификаты, ~3–4 недели соло + вечная поддержка ×2.
- Вывод спайка: стартовать только при 1000 платных; до этого PWA закрывает 90%.

## Триггер старта
`deploy/paid.sql → gate_pct >= 100` два месяца подряд (см. V27, V32).
