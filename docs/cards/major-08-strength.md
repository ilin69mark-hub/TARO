# 08 — Сила (major-08-strength.webp)

Ядро: `docs/cards/README.md` + seed якоря.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Композиция
Дуэт по центру: женщина слева-центр (x 35–55%), лев справа (x 55–80%), оба y 35–80%.
Фон — холмы и луна.

## Элементы (вид → роль → размер)
1. **Женщина** — вид: белое с золотом платье, венок из цветов, спокойное лицо вполоборота;
   роль: мягкая сила. НЕ борется — жест нежный.
2. **Рука на морде льва** — вид: ладонь мягко лежит на морде (x ~55%, y ~50%);
   роль: укрощение лаской. Пальцы простые!
3. **Лев** — вид: золотой, сидит, пасть ЗАКРЫТА (оскал запрещен!); роль: страсть под контролем.
   Крупнее женщины.
4. **Лемниската** — вид: светящаяся над головой женщины (рифма с Магом); роль: бесконечное
   терпение. Замкнута, без цифр.
5. **Цветы и холмы** — вид: цветущий луг, лунное небо; роль: мирная природа силы.

## Ловушки брака
- Пасть закрыта (оскал = другая карта!)
- Рука простая
- Лемниската без цифр

## ПЕРСОНАЖИ (супер-детализация)
**Женщина:** ~30, гибкая, невысокая. Лицо: овальное нежное, глаза опущены ВНИЗ НА ЛЬВА
(забота), губы — мягкая улыбка, нос маленький. Волосы: светло-каштановые распущены
с ВЕНКОМ из белых и золотых цветов (отличие от всех!). Одежда: 1) белое платье,
лен, свободное, БЕЗ узоров; 2) золотой пояс-шнур. Украшения: только венок.
Руки: ПРАВАЯ (СМЫСЛОВАЯ, исключение!) ладонь лежит на морде льва (пальцы расслаблены,
растопырены естественно — СЧИТАТЬ!); ЛЕВАЯ СКРЫТА складками платья. Ноги: босые в траве, стойка мягкая.
**Лев:** крупный (в 1.5 раза больше женщины), шерсть ЗОЛОТАЯ длинная с гривой-нимбом,
пасть ЗАКРЫТА, глаза полузакрыты (покой). Лапы большие, когти спрятаны. Сидит.
