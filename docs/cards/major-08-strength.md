# 08 — Сила (major-08-strength.webp)

Ядро: `docs/cards/README.md` + seed якоря.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Композиция
Дуэт по центру: женщина слева-центр (x 35–55%, y 35–80%), лев справа (x 55–80%, y 40–80%).
Фон — холмы (y 70–90%) и луна (y 8–18%). Все позиции — в % кадра 5:8.

## Элементы (вид → роль → размер)
1. **Женщина** — вид: белое с золотом платье, венок из цветов, спокойное лицо вполоборота;
   роль: мягкая сила. НЕ борется — жест нежный.
2. **Рука на морде льва** — вид: ладонь мягко лежит на морде (x ~55%, y ~50%);
   роль: укрощение лаской. Пальцы простые!
3. **Лев** — вид: золотой, сидит, пасть ЗАКРЫТА (оскал запрещен!); роль: страсть под контролем.
   Крупнее женщины.
4. **Лемниската** — вид: светящаяся над головой женщины (рифма с Магом); роль: бесконечное
   терпение. Замкнута, без цифр.
5. **Цветы и холмы** — вид: цветущий луг, лунное небо; роль: мирная природа силы.

## Ловушки брака
- Пасть закрыта (оскал = другая карта!)
- Рука простая
- Лемниската без цифр

## ПЕРСОНАЖИ (супер-детализация)
**Женщина:** ~30 лет, гибкая, невысокая, осанка мягкая. Лицо: овальное нежное, кожа
светлая гладкая, глаза опущены ВНИЗ НА ЛЬВА (забота, НЕ в камеру), губы — мягкая
полуулыбка, нос маленький прямой. Волосы: светло-каштановые распущены по плечам,
поверх — ВЕНОК из белых и золотых мелких цветов (отличие от всех! венок плотный,
цветы считать: 7–9 штук). Одежда по слоям: 1) белое платье, лен, свободное до земли,
рукава широкие до локтя, складки мягкие вертикальные; узоры: НЕТ (чистая ткань!);
2) золотой пояс-шнур на талии с узлом слева. Украшения: ТОЛЬКО венок (серег/колье НЕТ!).
Руки: ПРАВАЯ — СМЫСЛОВАЯ (исключение!): ладонь мягко лежит на морде льва (x ~55%,
y ~50%), пальцы расслаблены, растопырены естественно — СЧИТАТЬ 5!; ЛЕВАЯ СКРЫТА
складками платья (не рисовать!). Ноги/обувь: босые ступни в траве (пальцы простые),
стойка мягкая, одна нога чуть вперед.
**Лев:** крупный (в 1.5 раза больше женщины по массе, x 55–80%, y 40–80%), шерсть
ЗОЛОТАЯ длинная, грива-нимб вокруг морды кольцом. Морда: пасть ЗАКРЫТА (оскал запрещен!),
нос темный, глаза полузакрыты (покой). Лапы большие передние вместе, когти СПРЯТАНЫ.
Хвост лежит вдоль тела. Сидит смирно.
