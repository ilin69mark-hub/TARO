# Шаблон масти: ПЕНТАКЛИ (minor-pentacles-*.webp) — земля, материя

Ядро стиля: `README.md` (фикс-блок + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Фон масти (одинаковый для всех 14!)
Ночной сад/терраса: каменная балюстрада, кипарисы, виноградная лоза по арке,
вдали город с огнями. Теплая земляная гамма + золото (самая «домашняя» масть!).

## Центральный мотив по рангам
- **Туз:** один большой золотой пентакль в облачной руке над садом (рука В ОБЛАКЕ —
  только кисть с манжетой!). Диск золотой с пентаграммой-линиями (БЕЗ букв!).
- **02–10:** N пентаклей в дуге/сетке/дереве; число = рангу (пересчитать!). Диски
  одинаковые золотые, пентаграммы-линии (БЕЗ букв! пересечения без «лиц»).
- **Паж:** юная фигура 16–18 лет со спины рассматривает пентакль в руках.
- **Рыцарь:** всадник на черном коне, пентакль в руке, лицо вдаль (30 лет).
- **Королева:** сидящая среди цветов с пентаклем на коленях, лицо мягкое (40 лет).
- **Король:** сидящий на троне-быке с пентаклем и скипетром, лицо основательное (55 лет).

## ПЕРСОНАЖИ двора (по стандарту README!)
- **Паж:** 16–18, СО СПИНЫ (волосы каштановые, туника зеленая, лен, без узоров);
  обе руки держат пентакль перед собой на уровне груди (кисти простые); ноги скрыты;
  украшений НЕТ.
- **Рыцарь:** мужчина ~30, лицо вдаль спокойное, без бороды; доспех темный + зеленый
  плащ (шерсть); конь черный стоит (не мчится — отличие масти!); правая рука держит
  пентакль вверх, левая — повод.
- **Королева:** женщина ~40, лицо мягкое вполоборота, волосы темные с венком из
  мелких цветов; платье зелено-золотое (шелк, длинные рукава — руки hidden!);
  пентакль на коленях (диск золотой); сидит среди цветов; обувь скрыта; украшение:
  только венок.
- **Король:** мужчина ~55, лицо основательное с бородой, взгляд вперед-вдаль; мантия
  земляная с золотой каймой (бархат!); в правой — пентакль, в левой — скипетр;
  трон с быком у ног (бык малый стилизованный); обувь темная кожаная.
