# Туз мечи (minor-swords-ace.webp)

Ядро стиля: `README.md` (фикс-блок копипастом + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP 500×800 q80 <90KB. Все позиции — в % кадра 5:8.

## Фон масти (одинаковый для всех 14!)
Штормовое ночное небо: рваные фиолетовые тучи (y 0–50%), ветер гнет кипарисы по бокам (x 10% и 90%, y 40–80%), далекие горы (y 55–70%). Холодная резкая гамма, золото только на клинках/рукоятях (самая холодная масть!).

## Композиция
Один большой меч острием вверх по центру (x 48–52%, y 20–75%) из облака (облако серое, y 60–70%; только кисть с манжетой!). На острие — золотая зубчатая корона (малая, без букв!).
Ранг НЕ генерировать (цифры/буквы = брак!). Номер — оверлеем кодом Cormorant (см. T24/UI).

## Элементы (вид → роль → размер)
1. **Меч × 1** — вид: Меч: клинок прямой стальной с золотым отливом, рукоять золотая с крестовиной, длина ~35% высоты кадра. Клинки ПРЯМЫЕ (кривые = брак!). Одинаковые! роль: мера воздух, мысли. Ровно 1 штука — пересчитать!
2. **Фон** — вид: см. фон масти; роль: стихия воздух, мысли.
3. **Свет** — вид: золотые акценты на объектах, остальное — ночь; роль: премиум-контраст.

## Ловушки брака
- Клинки прямые (кривые = брак!)
- Крови/жестокости НЕТ (мечи как символы!)
- Рук минимум (мечи воткнуты/висят сами!)
- Объектов ровно 1 (пересчитать! лишние/недостающие = брак!)
- Пересечения простые, без узлов-«лиц» и без букв

## ОБЪЕКТЫ (супер-детализация)
Меч: клинок прямой стальной с золотым отливом, рукоять золотая с крестовиной, длина ~35% высоты кадра. Клинки ПРЯМЫЕ (кривые = брак!). Одинаковые! Материал: сталь + золото. Тканей/лиц нет (натюрморт масти!). Рук нет вообще (объекты стоят/висят сами — плюс против брака!). Размер: каждый ~35% высоты кадра.
