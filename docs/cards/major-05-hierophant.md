# 05 — Иерофант (major-05-hierophant.webp)

Ядро: см. `README.md` + seed якоря.

## Сцена
Фигура первосвященника на троне между двумя колоннами храма. Тройная золотая корона.
Рука поднята в благословении (два пальца — ПРОСТЫЕ жесты, см. ядро). У ног — два
молящихся силуэта спиной (лица не видны). Скрещенные ключи перед троном. Купол храма
сверху. Традиция, передача знания.

## Акценты
- Симметрия: колонны, молящиеся, ключи
- Жест руки простой, пальцы считаем!
- Золото короны — ярчайшее пятно

## Ловушки брака
- Рука благословения — главная зона брака (пальцы!)
- Лица молящихся не видны (спиной)
- Ключи без гравировок-букв
