# Рыцарь пентаклей (minor-pentacles-knight.webp)

Ядро стиля: `README.md` (фикс-блок копипастом + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP 500×800 q80 <90KB. Все позиции — в % кадра 5:8.

## Фон масти (одинаковый для всех 14!)
Ночной сад/терраса: каменная балюстрада (y 70–85%), кипарисы по бокам, виноградная лоза по арке сверху (y 5–20%), вдали город с огнями (y 55–65%). Теплая земляная гамма + золото (самая «домашняя» масть!).

## Композиция
всадник центр (x 30–70%, y 30–80%) в движении/стойке. Ранг НЕ генерировать (цифры/буквы = брак!). Номер — оверлеем кодом Cormorant (см. T24/UI).

## Элементы (вид → роль → размер)
1. **Фигура двора** — вид: см. ПЕРСОНАЖИ; роль: характер земля, материя ранга 12. Лицо — по матрице двора (пажи со спины!).
2. **Атрибут масти** — вид: Пентакль: диск золотой с пентаграммой-линиями (БЕЗ букв!), диаметр ~12% ширины кадра. Диски одинаковые (не разные монеты!). роль: знак масти.
3. **Трон/конь** — вид: трон/конь по рангу (рыцарь — конь, королева/король — трон); роль: статус.
4. **Фон** — вид: см. фон масти; роль: стихия земля, материя.

## Ловушки брака
- Пентаграммы — линии, не текст!
- Диски одинаковые (не разные монеты!)
- Рук минимум (пентакли висят/лежат сами!)
- Пажи — СТРОГО со спины (лицо = брак!)
- Взгляды двора — НЕ в камеру (вдаль/вполоборота!)
- Без букв на атрибутах

## ПЕРСОНАЖИ (супер-детализация)
**Рыцарь:** мужчина ~30, лицо вдаль спокойное без бороды. Доспех темный + зеленый плащ (шерсть). Конь черный СТОИТ (не мчится — отличие масти! все 4 ноги на земле). Правая рука держит пентакль вверх, левая — повод. Обувь: сапоги темные.
Возраст/тело/лицо/волосы/одежда по слоям/украшения/руки/ноги — см. выше (стандарт README: каждый пункт явно, узоры ДА/НЕТ, обувь, руки hidden/visible). Кисти простые, пальцы считать! Лишних конечностей нет.
