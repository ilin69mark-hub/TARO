# 07 — Колесница (major-07-chariot.webp)

Ядро: `docs/cards/README.md` + seed якоря.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Композиция
Фронтально: воин (x 40–60%, y 25–60%), колесница центр-низ (x 30–70%, y 55–90%),
сфинксы (y 70–90%: черный x 25–45%, белый x 55–75%, морды врозь), балдахин верх
(y 5–20%), стена фоном (y 40–60%). Все позиции — в % кадра 5:8.

## Элементы (вид → роль → размер)
1. **Воин** — вид: золотые доспехи, стоит прямо, взгляд вперед-даль; роль: воля.
   Лицо НЕ в камеру.
2. **Жезл** — вид: в правой руке вертикально; роль: направление. Пальцы проверить.
3. **Сфинксы** — вид: черный слева, белый справа, сидят симметрично (y 70–90%),
   морды врозь; роль: противоположности в упряжке. Морды стилизованы (не фото львов!).
4. **Балдахин** — вид: звездный полог сверху (y 5–20%); роль: небесное покровительство.
5. **Колеса и стена** — вид: колеса с золотой оковкой; городская стена фоном;
   роль: движение из старого.

## Ловушки брака
- Морды стилизованы
- Колесница фронтально (не боком)
- Рука с жезлом — пальцы

## ПЕРСОНАЖИ (супер-детализация)
**Воин:** мужчина ~30 лет, атлетичный. Лицо: юное мужественное, смотрит ВПЕРЕД-ВДАЛЬ
(подбородок поднят, НЕ в камеру — матрица!), кожа светлая, шлем ОТСУТСТВУЕТ (голова
открыта — отличие!). Волосы: темные короткие. Одежда по слоям: 1) золотой панцирь
с гравировкой (геометрия: концентрические дуги, НЕ буквы!); 2) белая туника под ним,
лен; 3) красный плащ за спиной (шерсть, складки вертикальные); 4) наплечники-полумесяцы
(луны! золотые). Украшения: золотая цепь с квадратной подвеской (гладкой, без букв!).
Руки: ПРАВАЯ держит жезл вертикально (жезл деревянный с золотым шаром! хват крепкий,
пальцы считать! x ~60%, y 35–55%); ЛЕВАЯ СКРЫТА за бортом колесницы (видна только
до локтя, правило рук!). Ноги: стойка широкая (x 42–58%), поножи золотые, сандалии
кожаные.
**Сфинксы (2, y 70–90%):** левый ЧЕРНЫЙ (x 25–45%), правый БЕЛЫЙ (x 55–75%), сидят
симметрично, тела львиные (лапы вместе, хвосты вдоль), головы человеческие
стилизованные (лица спокойные, НЕ фото! морды ВРОЗЬ!). Размер: каждый с колесницу
высотой. Без ошейников-надписей! **Колесница:** короб золотой с гербом-звездой
(геометрия!), колеса с золотой оковкой (спицы считать: по 8!).
