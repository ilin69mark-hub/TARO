# Шаблон масти: ЖЕЗЛЫ (minor-wands-*.webp) — огонь, действие

Ядро стиля: `README.md` (фикс-блок + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Фон масти (одинаковый для всех 14!)
Ночной пустынно-степной пейзаж: темно-фиолетовое небо, далекие дюны, одинокая
акация справа (y 60–80%). Вверху — маленькое золотое солнце-искра (рифма масти).
Земля теплого темного тона (единственная теплая масть!).

## Центральный мотив по рангам
- **Туз:** один большой золотой жезл вертикально из облачной руки (рука В ОБЛАКЕ —
  видна только кисть с манжетой! пальцев минимум). Жезл с зелеными листьями-побегами.
- **02–10:** N жезлов стоят/лежат веером/частоколом по центру, число = рангу
  (пересчитать! пересечения простые, без узлов-«лиц»). Жезлы одинаковые деревянные
  с золотыми наконечниками.
- **Паж:** юная фигура 16–18 лет со спины держит жезл вверх (лица нет).
- **Рыцарь:** всадник в движении, лицо под шлемом частично (как Колесница, 30 лет).
- **Королева:** сидящая фигура с жезлом, лицо вполоборота теплое (35 лет).
- **Король:** сидящая фигура с жезлом и саламандрой у ног, лицо зрелое вдаль (50 лет).

## ПЕРСОНАЖИ двора (по стандарту README!)
- **Паж:** 16–18, СО СПИНЫ (волосы рыжие короткие, туника песочная, лен, без узоров);
  руки подняты с жезлом вверх (кисти простые); ноги скрыты; украшений НЕТ.
- **Рыцарь:** мужчина ~30, лицо под открытым шлемом частично (подбородок поднят,
  взгляд вперед-даль); доспех легкий + красный плащ (шерсть); конь гнедой в движении;
  рука с жезлом вверх; вторая держит повод.
- **Королева:** женщина ~35, лицо вполоборота влево теплое, волосы темные с золотым
  обручем; платье тепло-оранжевое (шелк, длинные рукава — руки hidden!); жезл
  в правой руке вертикально; сидит на троне с львами-подлокотниками; обувь скрыта.
- **Король:** мужчина ~50, лицо зрелое вдаль с короткой бородой; мантия красная
  с золотой каймой (бархат!); в правой — жезл, левая на подлокотнике; у ног
  саламандра (малая, стилизованная); обувь темная.

## Оверлей номера (вместо генерации цифр!)
Ранг НЕ генерировать (цифры = брак!). Оверлей кодом Cormorant: римская цифра
вверху по центру золотом (см. T24/UI). Генерация — только сцена без цифр.

## Ловушки
- Рук минимум (жезлы сами стоят/лежат!)
- Цифр/букв ноль
- Огонь теплый, не неоновый
