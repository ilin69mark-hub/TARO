# Король кубков (minor-cups-king.webp)

Ядро стиля: `README.md` (фикс-блок копипастом + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP 500×800 q80 <90KB. Все позиции — в % кадра 5:8.

## Фон масти (одинаковый для всех 14!)
Ночное озеро: гладь воды — нижняя половина (y 50–100%) с лунной дорожкой по центру (x 45–55%), прибрежные ирисы по бокам (x 10% и 90%, y 75–90%), туман над водой. Холодная сине-фиолетовая гамма + золото луны (единственная водная масть!). Луна верх (x ~50%, y ~12%).

## Композиция
сидит на троне центр (x 35–65%, y 30–80%). Ранг НЕ генерировать (цифры/буквы = брак!). Номер — оверлеем кодом Cormorant (см. T24/UI).

## Элементы (вид → роль → размер)
1. **Фигура двора** — вид: см. ПЕРСОНАЖИ; роль: характер вода, чувства ранга 14. Лицо — по матрице двора (пажи со спины!).
2. **Атрибут масти** — вид: Кубок: золотой, чаша широкая, ножка высокая, без гравировки-букв! Высота каждого ~18% кадра. Одинаковые! роль: знак масти.
3. **Трон/конь** — вид: трон/конь по рангу (рыцарь — конь, королева/король — трон); роль: статус.
4. **Фон** — вид: см. фон масти; роль: стихия вода, чувства.

## Ловушки брака
- Вода отражает кубки (искаженно, рябь!)
- Кубки одинаковые золотые, без гравировок-букв
- Рук минимум (кубки стоят сами!)
- Пажи — СТРОГО со спины (лицо = брак!)
- Взгляды двора — НЕ в камеру (вдаль/вполоборота!)
- Без букв на атрибутах

## ПЕРСОНАЖИ (супер-детализация)
**Король:** мужчина ~50, лицо зрелое с легкой бородой, взгляд вдаль спокойный. Мантия сине-золотая (бархат, золотая кайма!). В правой — кубок, в левой — скипетр с шаром. Сидит на троне-волне (волны стилизованы). Обувь темная скрыта. Кольцо гладкое.
Возраст/тело/лицо/волосы/одежда по слоям/украшения/руки/ноги — см. выше (стандарт README: каждый пункт явно, узоры ДА/НЕТ, обувь, руки hidden/visible). Кисти простые, пальцы считать! Лишних конечностей нет.
