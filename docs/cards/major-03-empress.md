# 03 — Императрица (major-03-empress.webp)

Ядро: `docs/cards/README.md` + seed якоря.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Композиция
Теплый центр: трон y 35–75%, сад вокруг, ручей диагональю слева-вниз направо.
Единственная карта с зеленым акцентом (допустимо).

## Элементы (вид → роль → размер)
1. **Императрица** — вид: изумрудно-золотое платье, сидит на троне (x 35–65%, y 35–75%);
   роль: изобилие, забота. Лицо вполоборота, мягкое, НЕ в камеру.
2. **Корона с листьями** — вид: золотая с зелеными листьями (y ~28%); роль: природная власть.
   Без монограмм!
3. **Скипетр с шаром** — вид: в правой руке, шар золотой; роль: держава. Пальцы проверить!
4. **Трон в розах** — вид: каменный трон, увитый розами; роль: красота власти.
5. **Ручей с лунной дорожкой** — вид: диагональ y 70–90%; роль: течение жизни.
6. **Пшеница и розы** — вид: foreground по бокам; роль: плодородие.

## Ловушки брака
- Ночь обязательна (не дневная пастораль!)
- Рука со скипетром — пальцы
- Корона без букв
