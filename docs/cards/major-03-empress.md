# 03 — Императрица (major-03-empress.webp)

Ядро: `docs/cards/README.md` + seed якоря.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Композиция
Теплый центр: трон (x 35–65%, y 35–75%), фигура на троне, сад вокруг (x 5–95%,
y 60–100%), ручей диагональю слева-вниз направо (y 70–90%). Корона — верхняя точка
(y ~28%). Единственная карта с зеленым акцентом (допустимо). Все позиции — в % кадра 5:8.

## Элементы (вид → роль → размер)
1. **Императрица** — вид: изумрудно-золотое платье, сидит на троне (x 35–65%, y 35–75%);
   роль: изобилие, забота. Лицо вполоборота, мягкое, НЕ в камеру.
2. **Корона с листьями** — вид: золотая с зелеными листьями (y ~28%); роль: природная власть.
   Без монограмм!
3. **Скипетр с шаром** — вид: в правой руке, шар золотой; роль: держава. Пальцы проверить!
4. **Трон в розах** — вид: каменный трон, увитый розами; роль: красота власти.
5. **Ручей с лунной дорожкой** — вид: диагональ y 70–90%; роль: течение жизни.
6. **Пшеница и розы** — вид: foreground по бокам; роль: плодородие.

## Ловушки брака
- Ночь обязательна (не дневная пастораль!)
- Рука со скипетром — пальцы
- Корона без букв

## ПЕРСОНАЖИ (супер-детализация)
**Императрица (единственная):** женщина ~40 лет, статная, мягкие формы. Лицо: теплые
щеки с легким румянцем, кожа светлая, глаза карие смотрят ВПОЛОБОРОТА ВЛЕВО (мягко,
НЕ в камеру — матрица!), губы — спокойная полуулыбка, нос мягкий округлый. Волосы:
золотисто-каштановые, уложены волнами до плеч с вплетенными живыми розами и колосьями
(3 розы + 2 колоса!). Одежда по слоям: 1) нижнее платье кремовое, шелк, рукава длинные;
2) верхнее — изумрудное с ЗОЛОТОЙ вышивкой: розы и колосья (узор ДА, растительный,
вышивка плоская!); подол широкий лежит на троне (x 35–65%). Корона: золотая низкая
с зелеными живыми листьями (y ~28%, без монограмм!). Украшения: жемчужное ожерелье
(3 нити!), золотые браслеты на обеих руках (гладкие!). Руки: ПРАВАЯ держит скипетр
с шаром (скипетр золотой жезл, шар гладкий без гравировки! хват мягкий, пальцы
проверить!); ЛЕВАЯ полускрыта складками платья на подлокотнике (видна кисть частично).
Ноги: скрыты подолом, выглядывают золоченые туфли (носки, x 45–55%, y ~73%).
**Трон:** каменный светлый, увит живыми розами (5–7 цветков!).
