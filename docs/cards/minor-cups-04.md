# Четверка кубки (minor-cups-04.webp)

Ядро стиля: `README.md` (фикс-блок копипастом + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP 500×800 q80 <90KB. Все позиции — в % кадра 5:8.

## Фон масти (одинаковый для всех 14!)
Ночное озеро: гладь воды — нижняя половина (y 50–100%) с лунной дорожкой по центру (x 45–55%), прибрежные ирисы по бокам (x 10% и 90%, y 75–90%), туман над водой. Холодная сине-фиолетовая гамма + золото луны (единственная водная масть!). Луна верх (x ~50%, y ~12%).

## Композиция
4 кубков (Квадрат 2×2): Четыре объекта квадратом 2×2 (x 35–65%, y 35–65%). Строгая симметрия! Центр композиции x 30–70%, y 25–75%. Кубок: золотой, чаша широкая, ножка высокая, без гравировки-букв! Высота каждого ~18% кадра. Одинаковые!
Ранг НЕ генерировать (цифры/буквы = брак!). Номер — оверлеем кодом Cormorant (см. T24/UI).

## Элементы (вид → роль → размер)
1. **Кубок × 4** — вид: Кубок: золотой, чаша широкая, ножка высокая, без гравировки-букв! Высота каждого ~18% кадра. Одинаковые! роль: мера вода, чувства. Ровно 4 штук — пересчитать!
2. **Фон** — вид: см. фон масти; роль: стихия вода, чувства.
3. **Свет** — вид: золотые акценты на объектах, остальное — ночь; роль: премиум-контраст.

## Ловушки брака
- Вода отражает кубки (искаженно, рябь!)
- Кубки одинаковые золотые, без гравировок-букв
- Рук минимум (кубки стоят сами!)
- Объектов ровно 4 (пересчитать! лишние/недостающие = брак!)
- Пересечения простые, без узлов-«лиц» и без букв

## ОБЪЕКТЫ (супер-детализация)

Рук нет вообще (объекты стоят/висят сами — плюс против брака!). Размер: каждый ~18% кадра. Расположение: Квадрат 2×2 (Четыре объекта квадратом 2×2 (x 35–65%, y 35–65%). Строгая симметрия!).
