# 04 — Император (major-04-emperor.webp)

Ядро: см. `README.md` + seed якоря.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Композиция
Монолит: трон x 30–70%, фигура y 25–75%, горы фоном y 0–40%. Все горизонтали строгие.

## Элементы (вид → роль → размер)
1. **Император** — вид: красное с золотом одеяние поверх доспеха, сидит прямо;
   роль: структура, закон. Борода, взгляд вдаль (НЕ в камеру).
2. **Трон с баранами** — вид: каменный трон, подлокотники — стилизованные бараньи
   головы (декор, не реализм); роль: овновская воля.
3. **Скипетр-анх** — вид: в правой руке, крест с петлей; роль: жизнь через порядок.
   Без иероглифов!
4. **Голые горы** — вид: острые холодные пики за спиной; роль: незыблемость.
5. **Доспех** — вид: золотые наплечники из-под плаща; роль: готовность.

## Ловушки брака
- Лицо зрелое, не фото; взгляд НЕ в камеру
- Анх без иероглифов
- Фигура читается (не перетемнить)

## ПЕРСОНАЖИ (супер-детализация)
**Император (единственный):** мужчина ~55, мощный, широкоплечий. Лицо: ЕДИНСТВЕННАЯ
БОРОДА колоды — короткая седая аккуратно подстриженная; глаза серые смотрят ВДАЛЬ
ВПРАВО (строгость), нос крупный прямой, губы сжаты, лоб с морщинами власти. Волосы:
седые короткие из-под короны. Одежда: 1) доспех стальной с золотой гравировкой
(геометрия, НЕ буквы!); 2) поверх — красный плащ с золотой оторочкой, тяжелая ткань,
лежит симметрично; 3) туника темно-серая. Корона: золотая зубчатая (5 зубцов).
Украшения: массивное золотое кольцо-печатка на ПРАВОЙ руке (без монограммы!).
Руки: ПРАВАЯ держит анх (крест с петлей, гладкий; хват крепкий, пальцы считать!);
ЛЕВАЯ СКРЫТА под плащом (правило рук — жест не несет смысла).
Ноги: расставлены властно, сапоги кожаные до колена с золотой окантовкой.
