# 04 — Император (major-04-emperor.webp)

Ядро: см. `README.md` + seed якоря.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Композиция
Монолит: трон (x 30–70%, y 35–80%), фигура (x 35–65%, y 25–75%), горы фоном
(y 0–40%). Все горизонтали строгие. Взгляд — вдаль вправо. Все позиции — в % кадра 5:8.

## Элементы (вид → роль → размер)
1. **Император** — вид: красное с золотом одеяние поверх доспеха, сидит прямо;
   роль: структура, закон. Борода, взгляд вдаль (НЕ в камеру).
2. **Трон с баранами** — вид: каменный трон, подлокотники — стилизованные бараньи
   головы (декор, не реализм); роль: овновская воля.
3. **Скипетр-анх** — вид: в правой руке, крест с петлей; роль: жизнь через порядок.
   Без иероглифов!
4. **Голые горы** — вид: острые холодные пики за спиной; роль: незыблемость.
5. **Доспех** — вид: золотые наплечники из-под плаща; роль: готовность.

## Ловушки брака
- Лицо зрелое, не фото; взгляд НЕ в камеру
- Анх без иероглифов
- Фигура читается (не перетемнить)

## ПЕРСОНАЖИ (супер-детализация)
**Император (единственный):** мужчина ~55 лет, мощный, широкоплечий. Лицо:
ЕДИНСТВЕННАЯ БОРОДА колоды — короткая седая аккуратно подстриженная клином
(матрица!); глаза серые смотрят ВДАЛЬ ВПРАВО строго (НЕ в камеру, мимо!),
нос крупный прямой, губы сжаты, лоб с морщинами власти, кожа загорелая. Волосы:
седые короткие из-под короны. Одежда по слоям: 1) доспех стальной с золотой
гравировкой (геометрия-дуги, НЕ буквы!); 2) поверх — красный плащ с золотой
оторочкой шириной в ладонь по всему краю, тяжелая шерсть, лежит симметрично
двумя полами; 3) туника темно-серая, лен. Корона: золотая зубчатая (5 зубцов,
y ~22%). Украшения: массивное золотое кольцо-печатка на ПРАВОЙ руке (гладкое,
без монограммы! остального НЕТ!). Руки: ПРАВАЯ держит анх (крест с петлей,
золотой гладкий, хват крепкий, пальцы считать! x ~60%, y ~50%); ЛЕВАЯ СКРЫТА
под плащом (правило рук — жест не несет смысла, кисти не видно!).
Ноги: расставлены властно (x 40–60%), сапоги кожаные коричневые до колена
с золотой окантовкой верха.
**Трон:** каменный серый с подлокотниками — стилизованные бараньи головы (декор,
не реализм! завитки симметричны).
