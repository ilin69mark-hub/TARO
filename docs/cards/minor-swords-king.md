# Король мечей (minor-swords-king.webp)

Ядро стиля: `README.md` (фикс-блок копипастом + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP 500×800 q80 <90KB. Все позиции — в % кадра 5:8.

## Фон масти (одинаковый для всех 14!)
Штормовое ночное небо: рваные фиолетовые тучи (y 0–50%), ветер гнет кипарисы по бокам (x 10% и 90%, y 40–80%), далекие горы (y 55–70%). Холодная резкая гамма, золото только на клинках/рукоятях (самая холодная масть!).

## Композиция
сидит на троне центр (x 35–65%, y 30–80%). Ранг НЕ генерировать (цифры/буквы = брак!). Номер — оверлеем кодом Cormorant (см. T24/UI).

## Элементы (вид → роль → размер)
1. **Фигура двора** — вид: см. ПЕРСОНАЖИ; роль: характер воздух, мысли ранга 14. Лицо — по матрице двора (пажи со спины!).
2. **Атрибут масти** — вид: Меч: клинок прямой стальной с золотым отливом, рукоять золотая с крестовиной, длина ~35% высоты кадра. Клинки ПРЯМЫЕ (кривые = брак!). Одинаковые! роль: знак масти.
3. **Трон/конь** — вид: трон/конь по рангу (рыцарь — конь, королева/король — трон); роль: статус.
4. **Фон** — вид: см. фон масти; роль: стихия воздух, мысли.

## Ловушки брака
- Клинки прямые (кривые = брак!)
- Крови/жестокости НЕТ (мечи как символы!)
- Рук минимум (мечи воткнуты/висят сами!)
- Пажи — СТРОГО со спины (лицо = брак!)
- Взгляды двора — НЕ в камеру (вдаль/вполоборота!)
- Без букв на атрибутах

## ПЕРСОНАЖИ (супер-детализация)
**Король:** мужчина ~55, лицо властное с короткой седой бородой, взгляд вперед-мимо. Мантия синяя с золотой каймой. Меч в ножнах вертикально перед собой (обе руки на навершии!). Трон каменный высокий. Обувь темная. Кольцо-печатка гладкое.
Возраст/тело/лицо/волосы/одежда по слоям/украшения/руки/ноги — см. выше (стандарт README: каждый пункт явно, узоры ДА/НЕТ, обувь, руки hidden/visible). Кисти простые, пальцы считать! Лишних конечностей нет.
