# Шаблон масти: МЕЧИ (minor-swords-*.webp) — воздух, мысли

Ядро стиля: `README.md` (фикс-блок + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Фон масти (одинаковый для всех 14!)
Штормовое ночное небо: рваные фиолетовые тучи, ветер гнет кипарисы по бокам,
далекие горы. Холодная резкая гамма, золото только на клинках (самая холодная масть!).

## Центральный мотив по рангам
- **Туз:** один большой меч острием вверх из облачной руки (рука В ОБЛАКЕ — только
  кисть с манжетой!), корона на острие (золотая зубчатая, без букв!). Клинок прямой
  стальной с золотым отливом.
- **02–10:** N мечей воткнуты в землю/висят в воздухе веером; число = рангу
  (пересчитать! клинки ПРЯМЫЕ, пересечения без узлов-«лиц»). Мечи одинаковые.
- **Паж:** юная фигура 16–18 лет со спины держит меч вверх обеими руками (лица нет).
- **Рыцарь:** мчащийся всадник с занесенным мечом, лицо решительное вдаль (28 лет).
- **Королева:** сидящая с мечом на коленях, лицо строгое мимо камеры (40 лет).
- **Король:** сидящий с мечом в ножнах вертикально, лицо властное (55 лет).

## ПЕРСОНАЖИ двора (по стандарту README!)
- **Паж:** 16–18, СО СПИНЫ (волосы темные короткие, плащ серо-голубой, лен, без узоров);
  ОБЕ руки держат меч вверх (кисти простые, считать!); ноги скрыты; украшений НЕТ.
- **Рыцарь:** мужчина ~28, лицо решительное вдаль-мимо (подбородок вперед, без бороды);
  доспех стальной + белый плащ развевается (шерсть); конь серый мчится; правая рука
  занесла меч, левая держит повод.
- **Королева:** женщина ~40, лицо строгое мимо камеры влево, волосы убраны под тонкий
  обруч; платье серо-синее строгое (парча, без узоров!); меч лежит на коленях
  горизонтально; руки на мече (кисти простые); обувь скрыта; украшений НЕТ.
- **Король:** мужчина ~55, лицо властное с бородой короткой седой, взгляд вперед-мимо;
  мантия синяя с золотой каймой; меч в ножнах вертикально перед собой (обе руки
  на навершии!); трон каменный высокий; обувь темная.
