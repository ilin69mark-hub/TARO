# Шаблон масти: МЕЧИ (minor-swords-*.webp) — воздух, мысли

Ядро стиля: `README.md` (фикс-блок + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Фон масти (одинаковый для всех 14!)
Штормовое ночное небо: рваные фиолетовые тучи, ветер гнет кипарисы по бокам,
далекие горы. Холодная резкая гамма, золото только на клинках (самая холодная масть!).

## Центральный мотив по рангам
- **Туз:** один большой меч острием вверх из облачной руки (рука В ОБЛАКЕ!),
  корона на острие.
- **02–10:** N мечей воткнуты в землю/висят в воздухе веером; число = рангу.
- **Паж:** юная фигура со спины держит меч вверх обеими руками (лица нет).
- **Рыцарь:** мчащийся всадник с занесенным мечом, лицо решительное вдаль.
- **Королева:** сидящая с мечом на коленях, лицо строгое мимо камеры.
- **Король:** сидящий с мечом в ножнах вертикально, лицо властное.

## Оверлей номера
Ранг НЕ генерировать. Оверлей Cormorant римской цифрой (см. T24/UI).

## Ловушки
- Клинки прямые (кривые = брак!)
- Крови/жестокости НЕТ (мечи как символы, не оружие убийства)
- Рук минимум
