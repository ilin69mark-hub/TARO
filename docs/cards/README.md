## Style-lock (вместо мифа про seed)
Seed фиксирует ШУМ, а не стиль — один seed на разных промптах стиль НЕ держит.
Замок стиля из 3 частей (все обязательны):
1. **Reference:** сгенерируй Мага (01) + рубашку (`back.md`) первыми. Каждую следующую
   карту генерируй С ПРИЛОЖЕННЫМ reference-изображением Мага (параметр style-reference
   твоего инструмента: `--sref`, `style reference`, `image prompt` — как умеет).
2. **Style-token:** добавь в КАЖДЫЙ промпт дословно: `in the style of dark violet and
   antique gold occult tarot, Art Nouveau frames, cinematic candlelight` (помимо ядра).
3. **Seed:** зафиксируй seed якоря и переиспользуй — как ДОПОЛНЕНИЕ к п.1–2, не вместо.

## Параметры генерации (выставить и не менять всю колоду)
- Соотношение сторон: **5:8** (`--ar 5:8` / соответствующий параметр).
- Качество: high/detail, steps ≥30 (или пресет quality твоего инструмента).
- Stylize/CFG: среднее (перекрут дает дрейф палитры!). Запиши использованные значения сюда:
  `sampler: …; steps: …; CFG/stylize: …; ar: 5:8` /// ⛔ ВПИСАТЬ после первых проб ///
- Цвета словами (генераторы игнорируют HEX!): `deep violet night, antique gold`.
  HEX `#0B0B14` / `#D4AF37` — только для ПИПЕТКИ-Чека готовых файлов (ниже).

## Стандарт персонажа (дописывать в КАЖДЫЙ промпт, см. файлы)
Каждый humanoid описывается блоком: возраст/тело → лицо (форма, глаза, нос, губы,
выражение, КУДА СМОТРИТ) → волосы → одежда по слоям (ткань, цвет, складки, отделка,
узоры ДА/НЕТ явно) → украшения → руки (поза, пальцы) → ноги/обувь.

## Правило рук (строго!)
Руки — главная зона брака генераторов. Принцип: **рука, не несущая смысла, ПРЯЧЕТСЯ**
(в рукава, за спину, вне кадра, за предметом), а не «рисуется простой».
Видимыми остаются ТОЛЬКО руки-действия: жест Мага, благословение, весы/меч,
струя Умеренности, рука на морде. Остальные — hidden (прописано в файлах).

### Карта рук hidden/visible (сверяться!)
- 00: правая с цветком visible, левая с посохом visible (обе простые)
- 01: правая жест вверх visible, левая вниз visible
- 02–05, 09: hidden (рукава/посох/жезл минимум пальцев)
- 06, 07, 08, 11, 14: смысловые visible (считать пальцы!), вторые hidden
- 10, 16, 18: рук НЕТ (существа/архитектура)
- 12: за спиной hidden; 13: в перчатках; 15: правая открыта + факел
- 17, 19, 20, 21: с кувшинами/знаменами/жезлами visible упрощенно

## Брак-чеклист каждой карты
- [ ] Руки: нет лишних пальцев/деформаций
- [ ] Лица: сверить с МАТРИЦЕЙ выше (не повтор!)
- [ ] Текст: ни одной буквы/цифры
- [ ] Палитра словами: deep violet night + antique gold, без неона
- [ ] Пипетка-чек: фон `#0B0B14` ±8, золото `#D4AF37` ±12 (мерить в 3 точках!)
- [ ] Симметрия эмблемы по центру
- [ ] Узоры: только где указано ДА, иначе чистая ткань
- [ ] Лишних конечностей/торсов нет
