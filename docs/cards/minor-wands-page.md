# Паж жезлов (minor-wands-page.webp)

Ядро стиля: `README.md` (фикс-блок копипастом + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP 500×800 q80 <90KB. Все позиции — в % кадра 5:8.

## Фон масти (одинаковый для всех 14!)
Ночной пустынно-степной пейзаж: темно-фиолетовое небо (y 0–45%), далекие дюны (y 70–85%), одинокая акация справа (x ~75%, y 60–80%). Вверху — маленькое золотое солнце-искра (x ~50%, y ~10%). Земля теплого темного тона (единственная теплая масть!).

## Композиция
стоит, фигура центр (x 40–60%, y 35–80%). Ранг НЕ генерировать (цифры/буквы = брак!). Номер — оверлеем кодом Cormorant (см. T24/UI).

## Элементы (вид → роль → размер)
1. **Фигура двора** — вид: см. ПЕРСОНАЖИ; роль: характер огонь, действие ранга 11. Лицо — по матрице двора (пажи со спины!).
2. **Атрибут масти** — вид: Жезл: деревянный темный с золотым наконечником-шаром, у основания — зеленые листья-побеги (2–3 листика!). Длина каждого ~35% высоты кадра, толщина в руку. Одинаковые! роль: знак масти.
3. **Трон/конь** — вид: без трона (паж стоит); роль: статус.
4. **Фон** — вид: см. фон масти; роль: стихия огонь, действие.

## Ловушки брака
- Рук минимум (жезлы стоят/лежат сами!)
- Цифр/букв ноль
- Огонь теплый золотой, не неоновый
- Пажи — СТРОГО со спины (лицо = брак!)
- Взгляды двора — НЕ в камеру (вдаль/вполоборота!)
- Без букв на атрибутах

## ПЕРСОНАЖИ (супер-детализация)
**Паж:** 16–18 лет, СО СПИНЫ (лица нет! волосы рыжие короткие, туника песочная, лен, без узоров, складки вертикальные). Руки подняты с жезлом вверх (кисти простые, пальцы считать!). Ноги скрыты туникой. Украшений НЕТ. Жезл — как above, вертикально. Фон масти.
Возраст/тело/лицо/волосы/одежда по слоям/украшения/руки/ноги — см. выше (стандарт README: каждый пункт явно, узоры ДА/НЕТ, обувь, руки hidden/visible). Кисти простые, пальцы считать! Лишних конечностей нет.
