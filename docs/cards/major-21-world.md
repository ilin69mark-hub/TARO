# 21 — Мир (major-21-world.webp)

Ядро: `docs/cards/README.md` + seed якоря.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Композиция
Венок-мандорла: овал центр (x 25–75%, y 20–80%, ЗАМКНУТ!), фигура внутри по диагонали
(x 40–60%, y 30–75%), 4 существа по углам (~10% кадра каждое). Все позиции — в % кадра 5:8.

## Элементы (вид → роль → размер)
1. **Танцующая фигура** — вид: в развевающемся покрывале по спирали, лицо в движении,
   НЕ в камеру; роль: радость завершения. Целомудренно (покрывало!).
2. **Два жезла** — вид: в руках симметрично; роль: mastery обеих рук. Пальцы простые!
3. **Венок** — вид: большой золотой овал, ЗАМКНУТ полностью; роль: целостность, круг.
4. **4 существа** — вид: по углам в облаках (рифма с Колесом Фортуны); роль: гармония мира.
5. **Земля с холмами** — вид: внизу внутри/под венком; роль: обретенный дом.
6. **Анатомия танца** — конечности на местах (сложная поза — проверять!).

## Ловушки брака
- Анатомия! (вторая сложная поза колоды)
- Венок замкнут
- Фигура целомудренна

## ПЕРСОНАЖИ (супер-детализация)
**Танцовщица:** женщина ~25 лет, гибкая, стройная. Поза: ТАНЕЦ — одна нога поджата,
вторая вытянута по диагонали; руки разведены с ЖЕЗЛАМИ симметрично (в каждой по
жезлу: деревянные темные с золотыми наконечниками-шарами!). Лицо: в движении,
НЕ в камеру (профиль влево, смаз движения допустим), выражение радость, кожа светлая;
глаза в сторону (матрица: динамика!). Волосы: темные длинные развеваются по спирали
вместе с покрывалом. Одежда по слоям: 1) покрывало полупрозрачное белое с золотой
каймой (кайма шириной в палец по всему краю!), летит СПИРАЛЬЮ вокруг тела
(ткань видна, складки спиральные); 2) красная лента через тело по диагонали (шерсть);
узоры: НЕТ (чистая ткань + кайма!). Целомудренно (покрывало закрывает!).
Украшения: НЕТ. Руки: ОБЕ СМЫСЛОВЫЕ с жезлами (кисти держат древки, пальцы считать!);
Ноги: ступни босые (пальцы простые!), поза танца. Анатомия: КОНЕЧНОСТИ НА МЕСТАХ
(вторая сложная поза колоды — проверять! рук/ног ровно по 2!).
**Венок:** большой золотой овал (x 25–75%, y 20–80%), плетеный из лавра (листья
видны поштучно, 20+ листьев!), ЗАМКНУТ полностью (разрыв = брак!).
**4 существа по углам:** как у Колеса (ангел/орел/бык/лев), силуэты в облаках
(~10% кадра каждое, БЕЗ деталей!).
**Земля:** холмы и река внизу внутри венка (y 75–90%).
