# Туз жезлы (minor-wands-ace.webp)

Ядро стиля: `README.md` (фикс-блок копипастом + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP 500×800 q80 <90KB. Все позиции — в % кадра 5:8.

## Фон масти (одинаковый для всех 14!)
Ночной пустынно-степной пейзаж: темно-фиолетовое небо (y 0–45%), далекие дюны (y 70–85%), одинокая акация справа (x ~75%, y 60–80%). Вверху — маленькое золотое солнце-искра (x ~50%, y ~10%). Земля теплого темного тона (единственная теплая масть!).

## Композиция
Один большой золотой жезл вертикально по центру (x 48–52%, y 20–75%) выходит из облака (облако золотое клубящееся, y 60–75%). Видна только кисть в облаке с широкой манжетой (пальцев минимум!). Жезл с листьями-побегами.
Ранг НЕ генерировать (цифры/буквы = брак!). Номер — оверлеем кодом Cormorant (см. T24/UI).

## Элементы (вид → роль → размер)
1. **Жезл × 1** — вид: Жезл: деревянный темный с золотым наконечником-шаром, у основания — зеленые листья-побеги (2–3 листика!). Длина каждого ~35% высоты кадра, толщина в руку. Одинаковые! роль: мера огонь, действие. Ровно 1 штука — пересчитать!
2. **Фон** — вид: см. фон масти; роль: стихия огонь, действие.
3. **Свет** — вид: золотые акценты на объектах, остальное — ночь; роль: премиум-контраст.

## Ловушки брака
- Рук минимум (жезлы стоят/лежат сами!)
- Цифр/букв ноль
- Огонь теплый золотой, не неоновый
- Объектов ровно 1 (пересчитать! лишние/недостающие = брак!)
- Пересечения простые, без узлов-«лиц» и без букв

## ОБЪЕКТЫ (супер-детализация)
Жезл: деревянный темный с золотым наконечником-шаром, у основания — зеленые листья-побеги (2–3 листика!). Длина каждого ~35% высоты кадра, толщина в руку. Одинаковые! Материал: дерево + золото + листья. Тканей/лиц нет (натюрморт масти!). Рук нет вообще (объекты стоят/висят сами — плюс против брака!). Размер: каждый ~35% высоты кадра. Расположение: Туз: один большой по центру (Один большой объект — доминанта (x 42–58%, y 25–70%).).
