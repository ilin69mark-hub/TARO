# Шаблон масти: КУБКИ (minor-cups-*.webp) — вода, чувства

Ядро стиля: `README.md` (фикс-блок + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Фон масти (одинаковый для всех 14!)
Ночное озеро: гладь воды занимает нижнюю половину, луна с дорожкой по центру,
прибрежные ирисы и туман. Холодная сине-фиолетовая гамма + золото луны
(единственная водная масть!).

## Центральный мотив по рангам
- **Туз:** один большой золотой кубок в облачной руке над водой (рука В ОБЛАКЕ —
  видна только кисть с широкой манжетой белого рукава! пальцев минимум); из кубка
  льются 5 струй вниз (непрерывные!). Кубок — золото, чаша широкая, ножка высокая.
- **02–10:** N кубков стоят в ряд/пирамидой на берегу или плывут; число = рангу
  (пересчитать! пересечения простые, без узлов-«лиц»). Кубки одинаковые золотые.
- **Паж:** юная фигура 16–18 лет СО СПИНЫ (лица нет!) смотрит на кубок с рыбой внутри.
- **Рыцарь:** всадник на белом коне у воды, лицо вполоборота мягкое (25 лет).
- **Королева:** сидящая фигура с закрытым кубком на коленях, лицо спокойное вдаль (35 лет).
- **Король:** сидящий на троне-волне с кубком и скипетром, лицо зрелое (50 лет).

## ПЕРСОНАЖИ двора (по стандарту README!)
- **Паж:** возраст 16–18, со СПИНЫ (волосы светлые короткие, плащ голубой, лен,
  без узоров); руки держат кубок перед собой (кисти простые); ног не видно (плащ);
  украшений НЕТ.
- **Рыцарь:** мужчина ~25, лицо вполоборота вправо мягкое, без бороды; доспех легкий
  серебристый + голубой плащ (шерсть); руки: одна держит повод, вторая — кубок;
  сидит на белом коне (грива ухоженная).
- **Королева:** женщина ~35, лицо спокойное вдаль (НЕ в камеру), волосы темные убраны;
  платье бело-голубое, шелк, длинные рукава (руки hidden в рукавах!); на коленях
  ЗАКРЫТЫЙ кубок; украшение: только тонкий обруч; обувь скрыта.
- **Король:** мужчина ~50, лицо зрелое с легкой бородой, взгляд вдаль; мантия
  сине-золотая (бархат, золотая кайма!); в правой — кубок, в левой — скипетр;
  сидит на троне-волне (волны стилизованы); обувь темная скрыта.
