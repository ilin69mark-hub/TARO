# Шаблон масти: КУБКИ (minor-cups-*.webp) — вода, чувства

Ядро стиля: `README.md` (фикс-блок + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Фон масти (одинаковый для всех 14!)
Ночное озеро: гладь воды занимает нижнюю половину, луна с дорожкой по центру,
прибрежные ирисы и туман. Холодная сине-фиолетовая гамма + золото луны
(единственная водная масть!).

## Центральный мотив по рангам
- **Туз:** один большой золотой кубок в облачной руке над водой (рука В ОБЛАКЕ!),
  из кубка льются 5 струй.
- **02–10:** N кубков стоят в ряд/пирамидой на берегу или плывут; число = рангу.
- **Паж:** юная фигура со спины смотрит на кубок с рыбой внутри (лица нет).
- **Рыцарь:** всадник на белом коне у воды, лицо вполоборота (мягкое).
- **Королева:** сидящая фигура с закрытым кубком на коленях, лицо спокойное вдаль.
- **Король:** сидящий на троне-волне с кубком и скипетром, лицо зрелое.

## Оверлей номера
Ранг НЕ генерировать. Оверлей Cormorant римской цифрой (см. T24/UI).

## Ловушки
- Вода отражает (искаженно, рябь!)
- Кубки одинаковые золотые, без гравировок-букв
- Рук минимум (кубки стоят сами!)
