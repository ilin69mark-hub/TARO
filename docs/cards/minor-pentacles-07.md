# Семерка пентакли (minor-pentacles-07.webp)

Ядро стиля: `README.md` (фикс-блок копипастом + style-token + reference Мага) + параметры.
Размер: исходник 1000×1600, доставка 500×800 WebP 500×800 q80 <90KB. Все позиции — в % кадра 5:8.

## Фон масти (одинаковый для всех 14!)
Ночной сад/терраса: каменная балюстрада (y 70–85%), кипарисы по бокам, виноградная лоза по арке сверху (y 5–20%), вдали город с огнями (y 55–65%). Теплая земляная гамма + золото (самая «домашняя» масть!).

## Композиция
7 пентаклей (3+3+1): Семь объектов: два ряда по три + один верхний центр (x ~50%, y ~28%). Центр композиции x 30–70%, y 25–75%. Пентакль: диск золотой с пентаграммой-линиями (БЕЗ букв!), диаметр ~12% ширины кадра. Диски одинаковые (не разные монеты!).
Ранг НЕ генерировать (цифры/буквы = брак!). Номер — оверлеем кодом Cormorant (см. T24/UI).

## Элементы (вид → роль → размер)
1. **Пентакль × 7** — вид: Пентакль: диск золотой с пентаграммой-линиями (БЕЗ букв!), диаметр ~12% ширины кадра. Диски одинаковые (не разные монеты!). роль: мера земля, материя. Ровно 7 штук — пересчитать!
2. **Фон** — вид: см. фон масти; роль: стихия земля, материя.
3. **Свет** — вид: золотые акценты на объектах, остальное — ночь; роль: премиум-контраст.

## Ловушки брака
- Пентаграммы — линии, не текст!
- Диски одинаковые (не разные монеты!)
- Рук минимум (пентакли висят/лежат сами!)
- Объектов ровно 7 (пересчитать! лишние/недостающие = брак!)
- Пересечения простые, без узлов-«лиц» и без букв

## ОБЪЕКТЫ (супер-детализация)
Пентакль: диск золотой с пентаграммой-линиями (БЕЗ букв!), диаметр ~12% ширины кадра. Диски одинаковые (не разные монеты!). Материал: золото гладкое. Тканей/лиц нет (натюрморт масти!). Рук нет вообще (объекты стоят/висят сами — плюс против брака!). Размер: каждый ~12% ширины кадра. Расположение: 3+3+1 (Семь объектов: два ряда по три + один верхний центр (x ~50%, y ~28%).).
