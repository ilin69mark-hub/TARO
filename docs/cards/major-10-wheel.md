# 10 — Колесо Фортуны (major-10-wheel.webp)

Ядро: `docs/cards/README.md` + seed якоря.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Композиция
Мандала: колесо строго по центру (x 25–75%, y 25–65%), 4 существа по углам,
змей и Анубис по бокам внизу.

## Элементы (вид → роль → размер)
1. **Колесо** — вид: большое золотое, строго круглое; роль: цикл. На ободе —
   АЛХИМИЧЕСКИЕ ЗНАКИ СТИХИЙ (геометрия!). ГЛАВНАЯ ЛОВУШКА: генератор любит писать
   БУКВЫ (TARO/ROTA) — запретить явно!
2. **Ось-солнце** — вид: золотой диск в центре; роль: неподвижный центр перемен.
3. **4 существа** — вид: ангел, орел, бык, лев в облаках по углам, силуэты;
   роль: стражи направлений. Морды стилизованы.
4. **Змей и Анубис** — вид: по бокам внизу, стилизованные; роль: нисхождение/восхождение.
5. **Небо** — вид: фиолетовое с золотыми искрами; роль: космос цикла.

## Ловушки брака
- НИ ОДНОЙ БУКВЫ на колесе!
- Колесо круглое (не эллипс)
- Морды не фото
