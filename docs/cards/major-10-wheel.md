# 10 — Колесо Фортуны (major-10-wheel.webp)

Ядро: `docs/cards/README.md` + seed якоря.
Размер: исходник 1000×1600, доставка 500×800 WebP.

## Композиция
Мандала: колесо строго по центру (x 25–75%, y 25–65%, диаметр ~40% ширины),
4 существа по углам (каждое ~15% кадра: x 10–25% / 75–90%, y 15–30% / 70–85%),
змей слева-внизу и Анубис справа-внизу (y 70–90%). Все позиции — в % кадра 5:8.

## Элементы (вид → роль → размер)
1. **Колесо** — вид: большое золотое, строго круглое; роль: цикл. На ободе —
   АЛХИМИЧЕСКИЕ ЗНАКИ СТИХИЙ (геометрия!). ГЛАВНАЯ ЛОВУШКА: генератор любит писать
   БУКВЫ (TARO/ROTA) — запретить явно!
2. **Ось-солнце** — вид: золотой диск в центре; роль: неподвижный центр перемен.
3. **4 существа** — вид: ангел, орел, бык, лев в облаках по углам, силуэты;
   роль: стражи направлений. Морды стилизованы.
4. **Змей и Анубис** — вид: по бокам внизу, стилизованные; роль: нисхождение/восхождение.
5. **Небо** — вид: фиолетовое с золотыми искрами; роль: космос цикла.

## Ловушки брака
- НИ ОДНОЙ БУКВЫ на колесе!
- Колесо круглое (не эллипс)
- Морды не фото

## ПЕРСОНАЖИ (супер-детализация)
Людей НЕТ (только существа — отличие от всех! лицо в матрице: НЕТ, силуэты).
**4 крылатых существа по углам** — СИЛУЭТЫ в золотых облаках, размер каждого ~15%
кадра: ангел-человек (верх-лево, светлое пятно вместо лица), орел (верх-право, клюв
крючком стилизованный), бык (низ-лево, рога дугой), лев (низ-право, грива-нимб).
Крылья перистые бело-золотые, перья рядами (считать ряды, не перья!), тела скрыты
облаками по грудь. Каждый держит/читает ЗАКРЫТУЮ КНИГУ (обложка темная, БЕЗ букв!).
Лица: только намеки (клюв/морда стилизованы, ангел — светлое пятно). Рук-ног НЕ видно
(скрыты облаками — плюс против брака!).
**Змей** (слева внизу, x ~20%, y ~75%): золотая змея спиралью вниз, чешуя геометрией,
голова опущена. **Анубис** (справа внизу, x ~80%, y ~75%): черная шакалья фигура
с посохом, египетский профиль строгий, НЕ фото (стилизация!). Одежда: короткая
набедренная повязка темная; украшений НЕТ.
**Колесо:** золотое, диаметр ~40% ширины кадра; обод поделен на 8 секторов со знаками
стихий (геометрия: треугольники/волны/круги — НЕ буквы! НИ ОДНОЙ БУКВЫ!);
спицы ровные 8 шт; центр — солнечный диск с лицом-точкой условным (глаза-точки,
улыбка-дуга, anti-uncanny).
