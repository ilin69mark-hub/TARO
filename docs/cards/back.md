# Рубашка колоды (card-back.webp) — ОБЯЗАТЕЛЬНА к генерации ПЕРВОЙ вместе с Магом

Ядро стиля: `docs/cards/README.md` (тот же фикс-блок) + seed якоря.
Размер: исходник 1000×1600, доставка 500×800 WebP. Имя файла: `card-back.webp`.

## Почему первая
Рубашку юзер видит 90% времени (колода, вытягивание, веер, анимации). Она же —
визуальный эталон палитры для сверки всех 78 лиц (пипетка: фон и золото обязаны совпасть).

## Композиция — РЕВЕРС-СИММЕТРИЯ (критично!)
Рубашка при перевороте (180°) обязана выглядеть ОДИНАКОВО — иначе видны перевернутые
карты в веере. Весь узор строится с симметрией 180°: центр + 4 угла идентичны.

## Элементы (вид → роль → размер)
1. **Фон** — вид: глубокий фиолет ночи, равномерный, БЕЗ градиентных пятен;
   роль: спокойное поле. 100% кадра.
2. **Двойная рамка** — вид: внешняя золотая линия 6px на отступе 4% от края +
   внутренняя тонкая 2px на отступе 7%; роль: портал, рамка колоды. Углы рамок —
   маленькие золотые розетки-круги (4 шт, одинаковые!).
3. **Центральная эмблема** — вид: золотая восьмиконечная звезда в круге (диаметр ~30%
   ширины), внутри круга — полумесяц рожками вверх; роль: знак колоды. Строгая
   геометрия, циркуль!
4. **Узор поля** — вид: едва видимая сетка из точек/ромбов (opacity ~15%), шаг сетки
   равномерный; роль: текстура против плоскостности. БЕЗ крупных форм (не спорит
   с эмблемой!).
5. **Угловые розетки** — вид: 4 одинаковых золотых круга с точкой (диаметр ~6%);
   роль: якоря симметрии. Одинаковые пиксель в пиксель (проверка реверса!).

## Проверка реверса
Поверни результат на 180°: обязан совпасть с исходником. Нет — брак, перегенерируй.

## Ловушки брака
- Асимметрия углов (главная!)
- Буквы/монограммы в эмблеме (только геометрия!)
- Пятна градиента на фоне (фон ровный!)
- Звезда НЕ пятиконечная пентаграмма (восьмиконечная — нейтрально)
