# SECURITY_EXCEPTIONS — как читать аудитору

> Будущий аудит: сначала открой `security-exceptions.yml` и пропусти совпавшие `id+file`.
> Остальное проверяй как обычно, без скидок.
> Новое исключение — только записью в `yml` (ID, риск, кто принял, условие снятия).
> Маркер `AUDIT-EXCEPTION(E0x)` в коде без парного ID в `yml` — нарушение, CI падает.

Список A (человек/ключи) живёт в `security-exceptions.yml`: E01–E09.
Прод без закрытия E01–E08 не запускать.
