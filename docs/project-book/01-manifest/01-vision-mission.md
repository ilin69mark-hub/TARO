# Vision + Миссия

> Статус: `draft`. Связи: `02-audience-personas.md`, `03-usp-competitors.md`, `README.md`.

## 1. Vision (1 абзац)
«Онлайн Таро» — карманный вечерний ритуал самопознания для русскоязычной аудитории: за 2 минуты получить красивый, бережный и честный расклад с толкованием ИИ, без эзотерического мусора и страха. Мы не предсказываем судьбу — мы помогаем задать правильный вопрос себе.

## 2. Миссия продукта
- Давать опору в момент тревоги/выбора через структуру (карты + вопросы для рефлексии), а не через запугивание.
- Держать планку красоты: каждый экран — как кадр, которым хочется поделиться.
- Быть честным freemium: бесплатного хватает, чтобы влюбиться; платное — чтобы углубиться.

## 3. Проверка Vision (тест на уползание)
Любая фича отвечает «да» на все три:
1. Укладывается в 2-минутный ритуал?
2. Усиливает красоту/бережность/честность?
3. Работает на solo-поддержке (без ручного труда после релиза)?
Нет — в `05-antiscope.md` или в backlog `Could/Won't`.

## 4. Дефолтные формулировки для UI (связь с Tone of Voice)
- Подзаголовок лендинга: «Задай вопрос. Вытяни карты. Услышь себя.»
- Дисклеймер везде: «Это инструмент рефлексии, а не медицинская/юридическая консультация.»
