# Anti-scope — что НЕ делаем в MVP

> Статус: `draft`. Связи: `02-functional/01-moscow-map.md` (Won't), `06-rules/03-dod-frozen-scope.md`.

## Не делаем (сознательно)
1. Живых тарологов, чаты с экспертами, маркетплейс.
2. Email/пароль, OAuth Google/Apple — только Telegram ID + UUID.
3. Вторую колоду, конструктор раскладов, свои значения карт.
4. Нативные iOS/Android — только PWA (см. ADR-05).
5. Соцсеть: лента, комменты, подписки.
6. Английскую и другие локали — только RU + закладка i18n.
7. Рассрочки, промокоды сложнее % скидки, CPA-сети.
8. Видео/аудио толкования, медитации.
9. Детские аккаунты / 18- как отдельный режим — просто дисклеймер 18+ и рефлексия.
10. Ручную модерацию вопросов — только авто-фильтр запрещенки (медицина/суицид → безопасный ответ + контакты помощи).
11. В люксе НЕ делаем в MVP: ручную ретушь 78 артов, покупные 3D-модели, видео-петли на mobile, автоплей звука, крупные планы арта (камера ≥2.2м).

> Правило: запрос «а давайте добавим...» → сначала в `Won't`, потом в `Could` после релиза. Заморозка скоупа — в `06-rules`.
