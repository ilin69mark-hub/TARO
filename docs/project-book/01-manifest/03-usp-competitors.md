# USP и конкуренты

> Статус: `draft`. Связи: `01-vision-mission.md`, `05-design/01-direction-dark-magic.md`.

## 1. Конкуренты (что берем / чего избегаем)
| Приложение | Сила | Слабость (наш шанс) |
|---|---|---|
| Tarotoo (ES) | AI-толкования, SEO | испанский фокус, слабый RU, перегруз |
| Arcana (US) | красота, ритуальность | английский, подписка дорогая для RU |
| Labyrinthos | обучение, геймификация | сложный вход, не «за 2 минуты» |
| Golden Thread | минимализм | без AI-глубины, старое |

## 2. Наш USP (3 столпа)
1. **Русская глубина без мусора:** 78 карт + перевернутые + вопросы для рефлексии, tone поддерживающий. Не «тебя ждет беда», а «на что опереться».
2. **Ритуал за 2 минуты:** открыть → вытянуть → прочитать → сохранить. Никаких колод на выбор на старте, одна каноническая колода Райдера–Уэйта.
3. **Честный freemium + Telegram-нативность:** 1 free/день (дефолт, крутится в админке), вход за 5 сек через TG, оплата Stars без карт.

## 3. Позиционирование одной фразой
> «Самое красивое русскоязычное Таро с ИИ-толкованием, которое не пугает.»

## 4. Что НЕ является USP (чтобы не уползти)
- Не «точность предсказаний» — мы рефлексия.
- Не «100 колод» — одна колода, но идеально.
- Не «соцсеть тарологов» — никаких живых гадалок в MVP.
