# A11y минимум

> Статус: `audit-fix C`. Связи: `05-design/09-premium-temple.md`, `05-design/08-ultra-cinematic.md`.
- Контраст ≥4.5:1; gold `#D4AF37`/violet `#7C5CFF` на `#0B0B14` + поверх grain/vignette — просчитать отдельно; body violet/mist <16px на зерне запрещен; glow только Display ≥32px.
- Карты — кнопки `aria-label="Карта {n}"`, переворот — `aria-live`; canvas `aria-hidden=true` + DOM-дубль выбора (радиогруппа) с Tab-фокусом; tilt — только enhancement.
- Фокус gold outline, шрифт ≥16px, зум 200% ок.
- `prefers-reduced-motion` → Lite-статика: R3F off, letterbox off (сразу контент), CA/shake/flicker/grain/gyro/stagger/caret-blink off, streaming без анимации. Плюс ручной «Спокойный режим» в /profile (persisted, тот же маппинг).
