# Палитра (HEX)

> Статус: `draft`. Связи: `06-glass-gradients.md`.

| Роль | HEX | Использование |
|---|---|---|
| `bg-deep` | `#0B0B14` | фон app |
| `bg-card` | `#151524` | карточки |
| `bg-elev` | `#1E1E32` | модалки |
| `gold` | `#D4AF37` | акцент, CTA-рамка, фокус |
| `gold-soft` | `#F1D97B` | hover, свечение |
| `violet` | `#7C5CFF` | AI-стрим, градиенты |
| `mist` | `#A8A8C0` | вторичный текст |
| `paper` | `#F5F0E6` | основной текст |
| `success` | `#4ADE80` | оплата ок |
| `danger` | `#F87171` | ошибки |
| `overlay` | `rgba(11,11,20,.70)` | backdrop |

Контраст `paper` на `bg-deep` ≈ 15:1, `mist` ≈ 7:1. Tailwind-конфиг: `colors: {ink, card, gold, violet...}`.
