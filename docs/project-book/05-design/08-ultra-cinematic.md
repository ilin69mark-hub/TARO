# Ultra Cinematic (уровень C — решение frozen 2026-09-23)

> Статус: `frozen v1.0` (база для Premium). Связи: `01-direction-dark-magic.md`, `05-animations.md`, `06-glass-gradients.md`, `03-nonfunctional/01-performance.md`, `09-premium-temple.md` (надстройка).
> Решение: Ultra-шейдеры + AI-генерация 78 карт + «красота любой ценой» (LCP-бюджет ослаблен осознанно, детали в ADR-08). Premium-храм — в `09-premium-temple.md`, не дублировать.

## 1. Сцена (что видит юзер)
Letterbox-интро 1.2с (skippable) → туман-шейдер расходится от точки тапа → камера R3F наезжает на колоду → веер карт с foil → переворот с chromatic aberration + пыль → толкование поверх зерна/виньетки.

### 1.1 Главная: храм за заголовком (реализовано, 2026-09-29)

Владелец снял ограничения по качеству («делаем сразу очень дорого»), web — в
приоритете, натив позже. Главная получила полноценную сцену: тот же храм, что
на раскладе, но в режиме `muted` — вуаль гасит сцену и держит контраст текста,
а рубашка на алтаре остаётся единственным ярким пятном.

**Композиция.** `HomeHero.tsx`: 3D-сцена (lazy, `ssr:false`) → «кино-зал»
(`LandingIntro`) → контент. Вуаль на главной `0.32`, на раскладе `0.62` — при
0.62 храм превращался в неразличимую тень, и сцена переставала работать фоном.

**Что в храме** (`Temple.tsx`, всё procedural, без моделей и текстур из сети):
колонны из базы + ствола + капители, полукруглые арки между соседними,
4 ступени к алтарю, апсида-полукупол сзади, пол 60×60 с отражением,
процедурный мрамор (value-noise в цвет и шероховатость). Свечи — новый
`Candles.tsx`, пламя шейдерное, свет от пламени реальный.

**Свет сверху, а не из точки.** Лучи считаются по X, а не по полярному углу от
источника: свет в помещении падает из высоких окон и не расходится веером.
Полярная модель давала «солнечную звезду» ровно посередине кадра.

**Три ошибки, которые стоили дороже всего** — все на скриншотах, все по одной
причине: слой фона не согласован с геометрией.

| Симптом | Причина | Лечение |
|---|---|---|
| полоса поперёк кадра | `FogQuad` рисуется фоном (`depthTest:false`) и не затягивает геометрию; пол 14×14 обрывался чётко | `fogExp2` + пол 60×60 + цвет тумана светлее фона |
| кремовый «потолок» | `rayGold` в шейдере не нормирована, а `violet`/`gold` умножались на 0.20/0.08 — лучи давали 0.61 из 0.71 в красном | все константы нормированы вкладом; `uRays=0` гасит верх |
| силуэт апсиды с кромкой | цвет тумана сцены `#0B0B14` темнее фона шейдера (~0.10) | `FOG_MATCH` = `#12122b`, светлее ночного фона |

**Пост-стек** (`PostStack.tsx`): DOF (фокус на алтаре, размытые края уводят
взгляд в центр), Bloom, ChromaticAberration по краям, зерно, виньетка, SMAA.
LUT-грейдинг **выключен**: самодельная 3D-таблица 32×32 в `DataTexture`
отдавала почти чёрный кадр. ToneMapping в стеке тоже не включается — он уже
выставлен на `gl`, второй ACES поверх первого сжимал кадр.

**Инварианты** (покрыты `backdrop-muted.test.tsx` и `landing-intro.test.tsx`):
заголовок в серверном HTML без инлайн-стилей (LCP); 3D только через
`dynamic(ssr:false)` и его чанка нет в HTML страницы; вуаль различается для
главной и расклада; в сцене есть `fogExp2`; пол ≥30 единиц; пыль ограничена
клампом и отсевом у камеры; стенд закрыт без `NEXT_PUBLIC_DESIGN_LAB`.

**Стенд сцены** `/design-lab` — 18 слайдеров и 12 тумблеров слоёв. Собран по
ходу работы: локализация артефактов гашением слоёв заняла ~10 итераций, со
стендом — две секунды. Правило, которое из этого вышло: **сначала чинить
измерение, потом измерять** (стенд скроллился и показывал произвольный кусок
кадра, из-за чего я делал ложные выводы).

## 2. Стек (пины, проверить peerDeps; fiber@8 = React 18 + Next 14)
- `three@0.169.0`, `@react-three/fiber@8.17.10`, `@react-three/drei@9.114.3`, `@react-three/postprocessing@2.16.3`, `maath@0.10.8`, `lenis@1.1.14`, `framer-motion@11.11.9` (+ `react@18.3.1`, `next@14.2.x`).
- Фон: 1 fullscreen quad, GLSL nebula/fog (fbm 3 октавы, violet `#7C5CFF` 20% + gold `#D4AF37` 8%), параллакс pointer ×0.03 desktop; gyro только desktop `pointer:fine` + тогл (iOS `DeviceOrientation.requestPermission()` флоу: кнопка «Включить глубину» → permission → gyro, иначе touch).
- Карты: `meshPhysicalMaterial` + кастомный foil-shader (fresnel + value-noise перелив), tilt ±10° от pointer, `roughness .35 metalness .1`.
- Петли фона (только desktop, `matchMedia pointer:fine`): 2 WebM 5с loop <800KB (туман/звезды), `preload=none`, старт после `onload`.
- Звук: выкл по дефолту, drone mp3 <300KB по тоглу.

## 3. Пост-эффекты (порядок)
`Bloom (intensity .6, luminanceThreshold .75) → ChromaticAberration (offset .0012 только на перевороте 300мс) → Noise (opacity .08) → Vignette (.35)` + `text-glow 0 0 24px gold/30`.

## 5. Гейты (чтобы не сжечь телефоны)
- `deviceMemory<4` или `hardwareConcurrency<=4` или `reduced-motion` или «Спокойный режим» → Lite: статика + CSS-туман, без R3F/post.
- R3F только `dynamic import ssr:false` за `Suspense`; первый paint — CTA/текст без ожидания 3D (LCP мерим по нему).
- FPS-гард: `<28fps 1.5с → даунгрейд (reflector+bloom → тени → пыль → grain), <22fps → Lite`.
- SW-кэш: только 22 majors + шаблон + shell (остальные 56 lazy on-demand); 3D-чанк CacheFirst только desktop/wifi, mobile — NetworkFirst/Lite. CDN Cloudflare free.
