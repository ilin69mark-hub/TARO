# Флоу расклада + история

## User Story
Как пользователь, я хочу задать вопрос, вытянуть карты и получить толкование за 2 минуты, чтобы понять ситуацию.

## Шаги (≤3 клика)
1. Выбор расклада → ввод вопроса (опц., до 500 символов) → `POST /v1/readings` (проверка лимита).
2. Анимация вытягивания (рубашки → переворот) → карты фиксируются `seed` на бэке, шаффл Fisher–Yates.
3. AI-стриминг толкования (SSE) → сохранение → экран результата + CTA «сохранить/поделиться/еще».

## Acceptance Criteria
- Given free-лимит исчерпан, When POST readings, Then 402 `LIMIT_EXCEEDED` + paywall (не 500!).
- Given AI отвечает >25с, When таймаут, Then fallback: показываем значения карт из БД + «толкование придет пушем», джоба дописывает.
- Given повторный заход, When GET /v1/readings/:id, Then тот же текст (идемпотентность по `idempotency-key`).
- Given 78 карт, When шаффл, Then без дублей в раскладе + 15% шанс перевернутой (конфиг).

## Edge cases
| Кейс | Поведение |
|---|---|
| OpenRouter 5xx/таймаут | 2 ретрая (8с, 15с) → fallback-текст + `ai_logs status=failed` |
| Пустой/токсичный вопрос | фильтр: суицид/медицина → безопасный ответ + контакты помощи, вопрос не уходит в AI как есть |
| Двойной клик «вытянуть» | `Idempotency-Key` → один reading |
| Обрыв SSE | клиент `GET` дочитывает полный текст |

## История
- Последние 20 в `GET /v1/readings?limit=20`; premium — безлимит + поиск. Free видит только свои сегодняшние + blur старых с CTA.
