# Conventions — как пишем Книгу

> Статус: `draft`. Связи: `README.md`, `06-rules/02-code-style-naming.md`.

## 1. Именование файлов
- Папки: `NN-kebab` — `01-manifest`, `02-functional`.
- Файлы: `NN-kebab.md` — `01-vision-mission.md`. Только латиница, нижний регистр, дефис.
- Заголовок H1 внутри = русское название раздела.

## 2. Шаблон каждого файла
```md
# Название
> Статус: draft | frozen | Status + Связи: ссылки на другие файлы
## 1. ...
## 2. ...
```

## 3. Статусы
| Статус | Значение |
|---|---|
| `draft` | пишем, можно менять |
| `review` | готов к твоему ревью |
| `frozen` | зафиксировано в v1.0, менять только через ADR |

## 4. Стиль
- H1–H3, таблицы, списки. Без простыней текста.
- Конкретика: не «быстро», а `LCP < 2.5s`.
- Все цены/лимиты/флаги — как конфиг (`EntitlementsConfig`, `SpreadRegistry`), никогда хардкод в тексте. Пишем дефолтные значения + «меняется в админке».
- Связи указывать явно: `Связи: 02-functional/05-entitlements-billing.md`.

## 5. Definition of Done файла
- [ ] Есть Статус и Связи
- [ ] Нет TODO без владельца
- [ ] Ссылки из README работают
- [ ] Конкретика вместо абстракций
