# Месяц 4–6: критерий натива

> Статус: `draft`.
Натив (Expo RN) стартуем **только если 1000 платных подписчиков** (active). Почему: поддержка 2 сторов в соло убивает скорость; PWA закрывает 90% кейсов.
До этого: PWA-пуши, OG-шеринг, сезонные спреды через ротацию.
Если <1000: углубляем веб (дневник, Boosty), не распыляемся.
