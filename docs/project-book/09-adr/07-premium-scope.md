# ADR-07: Premium-храм в MVP (A-люкс + сдвиг +10 дней)

> Статус: `frozen`.
## Контекст
Ultra-база готова; запрос — премиум выше Ultra. Solo, $10 VPS, 78 AI-артов без ретуши.
## Варианты
- A-люкс: 3D храм (свет/пыль/камера/LUT) + сдвиг +10д. Плюс: вау; минус: FPS-риск, поддержка шейдеров.
- B-Lite: CSS/canvas атмосфера, в срок. Плюс: LCP<2.5s; минус: не «ошеломительно».
- C-отложить: запуск Lite, люкс после MRR≥30k. Плюс: скорость; минус: два дизайна.
## Решение
A: храм procedural (без внешних моделей), AI без ретуши, камера ≥2.2м, даунгрейд-лестница обязательна.
## Последствия
+ люкс в MVP; − LCP ослаблен (см. ADR-08), нужен перф-тест на iPhone 12 + Moto G54. Откат: Lite-флаг (R3F off) одной строкой.
