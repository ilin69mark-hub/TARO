# ADR-08: Бюджет LCP 2.5s → split (лендинг/3D)

> Статус: `frozen`.
## Контекст
Ultra+храм не влезают в LCP<2.5s mobile; `conventions` требует конкретику, predeploy/KPI требуют 2.5s.
## Варианты
- Держать 2.5s fail везде: убить 3D.
- Ослабить всё до 4/5s warn: легализация провала, бьет SEO.
- Split (выбрано): лендинг <2.5s fail + 3D <4.0/<5.0s warn (fail >5s), LCP по первому paint CTA без 3D.
## Решение
Split. Интро не блокирует LCP, 3D lazy после LCP.
## Последствия
+ честные гейты в 4 файлах (perf/KPI/predeploy/roadmap); − конверсия 3D-экранов ниже. Откат: Lite-статика возвращает <2.5s.
