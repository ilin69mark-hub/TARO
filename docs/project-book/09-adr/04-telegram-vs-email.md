# ADR-04: Telegram-auth, а не email

> Статус: `frozen`.
## Контекст
RU 20–45 в TG, нет желания помнить пароли, нет SMTP-бюджета.
## Варианты
- Email: пароли, письма, спам, +2 экрана.
- Telegram ID + UUID: вход 5 сек, Stars-оплата рядом, привязка в 1 тап.
## Решение
TG WebApp `initData` + anon UUID с последующим Link.
## Последствия
+ конверсия входа выше; − браузер без TG — anon (лечим QR «открой в TG»).
