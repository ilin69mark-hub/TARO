# ADR-06: Конфиг в админке, а не хардкод

> Статус: `frozen`.
## Контекст
Ты требуешь сам менять цены/лимиты/расклады без программиста.
## Варианты
- Хардкод: быстро, но каждый A/B — деплой, риск ошибки в проде ночью.
- `EntitlementsConfig` + `SpreadRegistry` в PG + Redis 5 мин + Publish: чуть дольше в нед. 2, но дальше свобода.
## Решение
Конфиг. Источник — `plans/spreads/app_config`, кэш Redis, audit.
## Последствия
+ ротация за минуты; − нужен `/admin` UI уже в MVP (минимум: таблицы + Publish).
