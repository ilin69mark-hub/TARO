# ADR-01: Go, а не Node

> Статус: `frozen`.
## Контекст
Solo-backend, пик 20:00–01:00, SSE-стрим AI, лимиты в Redis, один VPS $10.
## Варианты
- Node: быстрый старт, но event-loop проседает на SSE+ретраях, память растет.
- Go: строгая типизация, дешевые горутины под стрим, 1 бинарь в Docker, `pgx/sqlc`.
## Решение
Go 1.22 + chi.
## Последствия
+ держит 10k без рефакторинга; − медленнее писать MVP (компенсируем sqlc-генерацией). Откат: только через новый ADR после релиза.
