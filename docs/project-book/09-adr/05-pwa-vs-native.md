# ADR-05: PWA, а не натив

> Статус: `frozen`.
## Контекст
Solo, $10/мес, нужен запуск за 4 недели.
## Варианты
- Натив: 2 стора, ревью, пуши, но ×3 время.
- PWA: install за день, 1 кодовая база, offline-кэш карт.
## Решение
PWA; натив только при 1000 платных (см. роадмап).
## Последствия
+ скорость; − нет store-трафика (компенсируем SEO + TG).
