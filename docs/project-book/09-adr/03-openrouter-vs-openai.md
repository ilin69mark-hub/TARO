# ADR-03: OpenRouter, а не прямой OpenAI

> Статус: `frozen`.
## Контекст
Нужны дешевый RU-стрим, fallback-модели, оплата без US-карты.
## Варианты
- OpenAI напрямую: нужен US-биллинг, 1 модель, выше цена.
- OpenRouter: единый ключ, `gpt-4o-mini` + `claude-haiku` fallback, pay-as-you-go криптой/картой, логи токенов.
## Решение
OpenRouter, модель в конфиге.
## Последствия
+ переживаем падение 1 провайдера; − зависимость от посредника (лечим кэшем + лимитом токенов).
